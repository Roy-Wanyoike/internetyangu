## Summary
Fixes audit finding F-02: the dashboard captured API errors but never rendered them, leaving KPI cards in eternal "loading…". Introduces a reusable `ErrorState` component (what happened → what to do → retry) and wires it into every data-loading surface.

Closes #2

## Changes
- New `src/components/app/error-state.tsx`: `role="alert"` panel with title, specific failure message, and a Retry button (spinner while retrying).
- `overview-tab.tsx`: stats failure now renders an error panel in place of the KPI row (`statsError` dead state eliminated); outage-log failure renders an error panel instead of silently showing an empty list. Retry states tracked for both loaders.
- `spend-tab.tsx`, `providers-tab.tsx`, `outages-tab.tsx`: replaced bare destructive text with `ErrorState` + working Retry.
